# Dizozet - Premium Subscriptions & Viral Reels Bundles E-Commerce Platform

A complete, modern, digital e-commerce web application with a signature **White + Mint (`#a1e3d8`)** design theme, built for selling **Subscriptions** (with direct WhatsApp order flow to **7895768118**), **130+ Viral Reels Bundles**, and **Digital Products**.

---

## 🌟 Key Features

### 1. Branding & Design
- **Name**: **Dizozet**
- **Theme Color**: `#a1e3d8` (Mint / Soft Cyan) paired with clean white backgrounds and deep slate/teal typography.
- **Top Bar**: Clean header without cluttered announcement bars.
- **Navigation Bar**: Clean search icon button (no Ctrl+K badge), Home, Subscriptions, Reels Bundles (no extra badges), Digital Products, Cart, and My Orders.
- **Customer Reviews**: All Indian creators with name initial letter avatars (no photos).

### 2. Homepage
- **Hero Section**: Clean, focused, centered headline with 4 stats:
  - **30+ Subscriptions**
  - **130+ Reels Bundles**
  - **15K+ Happy Creators**
  - **Instant WhatsApp Delivery**
- **Subscriptions Section**: 4 popular subscriptions with starting prices and direct WhatsApp ordering.
- **Reels Bundles Section**: Top viral bundles with reel counts, 1080p HD badges, and instant checkout.
- **Digital Products Section**: Clean **Coming Soon** showcase.

### 3. Direct WhatsApp Order Flow for Subscriptions
- For all subscriptions, clicking **Buy Now** immediately opens **WhatsApp (7895768118)** with the selected product, plan duration, and price pre-filled for rapid activation.

## 🚀 How to Run

```bash
# Production server (runs on port 3001 or fallback if port is in use)
node server.js

# Or development server with hot-reload
npm run dev
```

Open in browser: **http://localhost:3001**
